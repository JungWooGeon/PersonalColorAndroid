# 데이터 보안 양식 답안 — 나의 컬러는? v2.0 (versionCode 23)

> 근거: 코드(2d6b7ef 기준)와 https://tintycolor.com/privacy.html (2026-11-01).
> Play 기준: 기기 안에서만 처리되는 데이터는 '수집'이 아니고, 기기 밖으로 나가는 데이터(SDK 포함)는 '수집'이에요.
> 서비스 제공자에게 앱 대신 처리를 맡기는 것과 사용자가 직접 요청한 전송은 '공유'가 아니에요.

## 1. 데이터 수집 및 보안 (첫 화면)

| 질문 | 답 |
|---|---|
| 필수 사용자 데이터 유형을 수집하거나 공유하나요? | **예** (AdMob, 날씨 조회, Play 결제) |
| 수집된 모든 사용자 데이터가 전송 중에 암호화되나요? | **예**: 날씨 요청은 `https://api.open-meteo.com`, 각 SDK는 HTTPS를 써요. 앱 자체 네트워크 코드는 `WeatherRepository` 한 곳뿐이에요. |
| 사용자가 데이터 삭제를 요청할 수 있는 방법을 제공하나요? | **예**: 앱 설정 → 진단 기록 전체 삭제 / 모든 데이터 초기화, 내 옷장 → 전체 삭제, 이메일 문의(wjddnrjs123@gmail.com). 광고 데이터는 설정 → 개인정보 옵션과 기기 광고 ID 재설정으로 관리해요. |

## 2. 데이터 유형별 답안

| 데이터 유형 | 수집 | 공유 | 일시적 처리 | 필수/선택 | 목적 | 출처 |
|---|---|---|---|---|---|---|
| 위치 › **대략적인 위치** | 예 | 예 | **아니요** | **필수** | 앱 기능, 광고 또는 마케팅, 분석, 사기 방지·보안·규정 준수 | ① 날씨: `ACCESS_COARSE_LOCATION`, 소수점 둘째 자리로 줄인 좌표를 Open-Meteo로 보냄 ② AdMob: IP 기반 대략적 위치 |
| 기기 또는 기타 ID › **기기 또는 기타 ID** | 예 | 예 | 아니요 | 필수 | 광고 또는 마케팅, 분석, 사기 방지·보안·규정 준수 | AdMob 광고 ID / 앱 세트 ID |
| 앱 활동 › **앱 상호작용** | 예 | 예 | 아니요 | 필수 | 광고 또는 마케팅, 분석, 사기 방지·보안·규정 준수 | AdMob 광고 노출·클릭 |
| 앱 정보 및 성능 › **비정상 종료 로그**, **진단** | 예 | 예 | 아니요 | 필수 | 분석, 사기 방지·보안·규정 준수 | AdMob SDK 진단 정보 (앱 자체 크래시 SDK는 없음) |
| 금융 정보 › **구매 내역** | 예 | 아니요 | 아니요 | **선택** (구매할 때만) | 앱 기능 | Play 결제 `premium` 구매 확인·복원. 구매 상태는 기기에만 캐시하고 운영자 서버로는 보내지 않아요 |

**위치 답을 고르는 기준**
- 날씨만 보면 '일시적 처리 예 · 선택 · 앱 기능'이 맞아요. 날씨는 위치 권한을 허용한 경우에만 조회하고, 거부하면 계절 기준으로 코디를 추천해요. 기기에는 날씨 결과만 최대 6시간 보관해요.
- 그런데 Play는 데이터 유형마다 답을 하나만 받아요. AdMob이 IP로 대략적 위치를 계속 수집하므로 합친 답은 위 표처럼 '일시적 아니요 · 필수'가 돼요. 목적에는 날씨용 '앱 기능'도 함께 체크하세요.

**공유를 '예'로 둔 이유**: AdMob 데이터는 Google 광고 네트워크에서 쓰이므로 보수적으로 '공유'에 체크했어요. 제출 직전에 Google의 [Google Mobile Ads SDK 데이터 공개 안내](https://developers.google.com/admob/android/privacy/play-data-disclosure)를 한 번 더 확인하세요.

## 3. '수집 안 함'으로 두는 항목과 근거

| 항목 | 판정 | 근거 |
|---|---|---|
| 사진 및 동영상 (진단 얼굴 사진) | 수집 안 함 | MediaPipe로 기기 안에서만 분석해요. 업로드 코드가 없고, 앱 자체 네트워크 코드는 날씨 하나뿐이에요. 드레이핑과 립 체험은 메모리에 있는 진단 사진만 써요(프로세스가 끝나면 사라짐). |
| 사진 (내 옷장) | 수집 안 함 | ML Kit 피사체 분할로 기기에서 배경을 지우고 `filesDir/closet/`에 저장해요. 클라우드 백업과 기기 이전 모두 제외돼요(`data_extraction_rules.xml`, `backup_rules.xml`). |
| 컬러 체크 사진 | 수집 안 함 | 사진 선택 도구나 시스템 카메라로 받은 사진을 기기에서 처리해요. |
| 카카오톡 공유 | 수집·공유 안 함 | 사용자가 직접 누를 때만 보내고, 내용은 톤 이름·소개 문구·`tintycolor.com/r/og/<톤>.png` 주소예요. 사용자 사진은 보내지 않아요. |
| 분석 (`core:analytics`) | 수집 안 함 | `Log.d`(Logcat)로만 남기고, 외부로 보내는 백엔드는 없어요(Firebase는 제거됨). |
| 크래시 로그 (앱 자체) | 수집 안 함 | Crashlytics나 Sentry가 없어요. AdMob 진단 정보만 위 표에 넣었어요. |
| 알림 | 수집 안 함 | AlarmManager로 기기에서 보내는 로컬 알림이에요. 푸시 서버나 FCM은 없어요. |
| 위젯 / 배경화면 | 수집 안 함 | 기기 안에서만 그려요. |
| 개인 정보, 연락처, 메시지, 건강, 오디오, 파일·문서, 캘린더, 웹 기록 | 수집 안 함 | 해당 기능이 없어요. |
| 진단 기록, 내 톤, 즐겨찾기, 설정 | 수집 안 함 | 기기 DataStore에 저장해요. 사용자 본인의 Google 백업에는 포함될 수 있지만, Play 기준으로 '수집'에 해당하지 않아요. |

## 4. 같이 답하는 항목 (앱 콘텐츠)

- **광고 ID**: 예, 사용함 → 목적: 광고 또는 마케팅, 분석, 사기 방지. (`play-services-ads`가 `AD_ID` 권한을 자동으로 병합해요.)
- **광고 포함**: 예.
- **동의**: Google UMP로 EEA·영국 등 필요 지역에서만 동의 화면을 띄우고, 설정 → 개인정보 옵션에서 다시 바꿀 수 있어요.

## 5. 개인정보처리방침과 코드가 다른 곳 (웹사이트 수정 필요)

1. **카메라·사진 권한 범위**: 방침은 "진단 기능 이용 시에만"이라고 쓰지만, 실제로는 컬러 체크와 내 옷장에서도 카메라와 사진 선택을 써요. → "진단, 컬러 체크, 내 옷장 기능 이용 시"로 고치세요.
2. **ML Kit 누락**: 방침에는 MediaPipe만 있어요. 실제로는 Google ML Kit 피사체 분할(Google Play 서비스, 기기 내 처리)로 옷 배경을 지우고, 드레이핑에서 인물을 분리해요. → 이 내용을 추가하세요.
3. **진단 결과 저장 항목**: 방침은 "톤 이름, 진단 날짜만"이라고 쓰지만, 기록에는 진단 방식(사진/질문)과 비슷한 톤 상위 3개의 확률값도 저장돼요(`HistoryEntry.top`). → "톤 이름, 진단 방식, 진단 날짜, 비슷한 톤 순위"처럼 고치세요.
4. **"기기 내부에만 저장"**: `allowBackup=true`이라 진단 기록·즐겨찾기·설정은 사용자 본인의 Google 백업에 포함될 수 있어요(옷장 사진만 제외). → "옷장 사진은 백업에서 제외되고, 그 밖의 설정·기록은 기기 백업 설정에 따라 사용자 Google 계정 백업에 포함될 수 있어요"를 추가하세요.
5. **AdMob 처리 항목**: 방침에 진단 정보(비정상 종료 등)가 빠져 있어요. 위 Play 답안과 맞추려면 "앱 진단 정보"를 추가하세요.
6. **삭제 방법**: 앱 안의 방침(LegalDocuments.kt)에는 "앱 설정에서 진단 기록만 삭제할 수도 있습니다"가 있는데 웹사이트에는 없어요. 옷장 전체 삭제도 둘 다 빠져 있어요. → 웹사이트에 추가하세요.
7. **호스팅 사업자**: 웹사이트 5항은 Netlify로 적혀 있어요. tintycolor.com이 지금도 Netlify에 있는지 확인하세요.
8. *(코드 쪽 문제)* **촬영 원본이 캐시에 남음**: 가이드 카메라가 `cacheDir/guided_<시간>.jpg`에 저장한 뒤 지우지 않아요(앱 전용 영역이고 외부로 나가지는 않음). "앱은 사진 원본을 별도로 보관하지 않습니다"와 어긋나요. → 웹사이트보다 코드에서 분석 후 삭제하는 쪽이 맞아요. 컬러 체크 카메라는 고정 파일명이라 덮어쓰지만, 마찬가지로 남아 있어요.
9. *(참고)* 동네 이름은 시스템 Geocoder로 바꾸는데, 기기에 따라 Google 서버에 물어볼 수 있어요. 지금 문구("기기의 위치 서비스로 처리")도 틀리지는 않아요.
